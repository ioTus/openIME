# Principles — Index

Standing decisions and values. Treat as settled unless the user reopens
one. Read a principle when the work touches its domain.

- `agents-are-not-avatars.md` — an agent acts on a person's behalf; it is
  not a stand-in for the person
- `connection-failure-protocol.md` — degraded-mode drafting and the
  queue manifest when the repository transport fails; recovery steps
  live in each platform's adapter
- `data-sovereignty.md` — the human owns their data; standing principle
- `no-intent-no-grant.md` — context and tool grants scoped by declared
  intent, not persona alone
- `para-knowledge-organization.md` — filing heuristic and directory
  conventions for `knowledge/`
- `return-the-result-not-the-context.md` — what crosses a scope
  boundary: results, never working context
- `say-what-to-do.md` — instructions to builder agents state the action,
  not the precondition

Add your own standing decisions here as one file each, and list them
above. A principle is a settled call you want every session to honor.
