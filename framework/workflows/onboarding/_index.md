# Onboarding — Index

Transition procedures and canonical templates. List this directory
before answering any setup or "how do I add X" question. Never
scaffold a governance file from memory; copy the template here.

- `workflow.md` — the guided "Set up IME" flow; triggered only by that
  phrase
- `spoke-setup.md` — step-by-step checklist for adding a project with a
  Replit builder
- `spoke-setup-claude-code.md` — checklist for a spoke whose builder
  is Claude Code in a local clone (native git, no sync utility)
- `github-push-utility.md` — reference for the sync utility Replit uses
  instead of `git push`; version record lives in
  `framework/maintenance.md`
- `spoke-ime-md.template.md` — canonical `IME.md` for a spoke
- `spoke-ime-agents-md.template.md` — canonical `IME-AGENTS.md`
- `spoke-ime-agents-replit-md.template.md` — canonical
  `IME-AGENTS-replit.md`
- `spoke-ime-agents-claude-code-md.template.md` — canonical
  `IME-AGENTS-claude-code.md`
- `spoke-claude-md.template.md` — canonical `CLAUDE.md` pointer stub
  for a Claude Code spoke
- `replit-md-template.md` — IME sections appended to a spoke's
  `replit.md`
