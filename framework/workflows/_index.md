# Workflows — Index

  canonical governance templates → `onboarding/_index.md`
- `pm-builder/` — Claude → GitHub → builder-agent pipeline
  → `pm-builder/_index.md`
- `parallel-threads/` — coordinating several autonomous agent threads
  through the repo → `parallel-threads/_index.md`
