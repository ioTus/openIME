# knowledge/ — Index

Personal content, organized by PARA. Yours; keep the repository
private.
Filing rules: `framework/principles/para-knowledge-organization.md`.

- `projects/` — active work with a goal and an end → `projects/_index.md`
- `areas/` — ongoing responsibilities, no end date → `areas/_index.md`
- `resources/` — reference library and signal library
  → `resources/_index.md`
- `archive/` — inactive items from the other three → `archive/_index.md`

Each project or area carries a `_config.md` (what the project layer
points at) and an `_index.md` (what the folder holds).
